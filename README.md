# Maritime Fleet Context-Aware AI FDE Case Repository

This repository is a rebuilt, architecture-native version of the original maritime/fleet case. It is designed for AI Forward Deployed Engineers to learn how enterprise evidence becomes **semantics → ontology → connected knowledge → hybrid retrieval → runtime context → controlled AI/agent support → audit/feedback**, followed by a traceable PRD and Google AI Build prototype.

## Start

Open `START_HERE.md`.

## Important case boundary

The application is **decision support**. It is not autonomous vessel navigation/control. The Master and defined technical/safety authorities remain authoritative. Essential vessel-side workflow must survive shore/cloud/AI outage.

## Repository shape

- `evidence/` — heterogeneous synthetic operational evidence, policies, semantic clues and golden scenarios
- `architecture/` — concept and architecture challenge guidance
- `participant_templates/` — 15 required participant deliverables
- `google_ai_build/` — PRD prompt, build prompt, screen/acceptance requirements and consolidated fixture bundle
- `scripts/` — deterministic fixture/profile/QA utilities
- `reference_visuals/` — the architecture source ideas used for the rebuild

All data is synthetic and for workshop use only.
