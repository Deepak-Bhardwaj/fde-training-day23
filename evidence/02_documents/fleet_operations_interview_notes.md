# Fleet Operations SME Interview Notes

- Controllers say the slowest part is not finding one datum; it is reconciling **which version is current and which constraint has authority**.
- During outages, vessel and shore teams can each be correct relative to different clocks and data snapshots.
- Port API fields use different meanings for “available”, “confirmed” and “open”.
- A plan can look commercially optimal but become infeasible when cargo, crew-rest or CMMS constraints arrive late.
- Operators want a concise evidence-backed recovery comparison, not a chatbot conversation.
- Post-event learning is weak because rationale, source freshness and later outcome are not linked consistently.
